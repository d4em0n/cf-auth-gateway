| Actual Cloudflare origin boundary         | Staging origin login/assets/private API reject missing/wrong secrets with 403 through Cloudflare, including spoofed forwarding headers; correct-secret trusted access and gateway traffic work. Strict TLS is scoped to staging origin.                             |
| Actual Cloudflare origin access logs      | Unique markers prove anonymous and invalid protected requests did not reach protected origin handlers, valid first use did, recognized repeat skipped `/api/user`, and recognized expired JWT reached `/api/convos` and received 401 without revalidation.          |

Backend logout invalidates refresh sessions; a still-unexpired access JWT returned 200 after logout and expired normally. The gateway deliberately preserves that backend policy. Short QA token lifetimes differ from the owner's default 15 minutes. Parallel refresh behavior is backend timing-dependent; native clients must serialize renewal and keep rotated cookies.

Native Android acceptance and additional stream-resumption checks are being completed in this branch. No physical iOS client, enabled OIDC/Google/passkey enrollment, public shared-link policy, multi-region KV convergence, global quota behavior, or production hostname cutover is claimed. Generic WebSocket messages/close are verified in workerd; LibreChat conversations use SSE and do not establish an application WebSocket.

Public CI status and final native results will be updated with the completed development commit. Private evidence contains only disposable-account state and is not published as GitHub artifacts.
