Backend logout invalidates refresh sessions; a still-unexpired access JWT returned 200 after logout and expired normally. The gateway deliberately preserves that backend policy. Short QA token lifetimes differ from the owner's default 15 minutes. Parallel refresh behavior is backend timing-dependent; native clients must serialize renewal and keep rotated cookies.

Conduit **4.3.1 Android debug** passed real Cloudflare login, model/endpoint discovery, conversations, a streamed `NATIVE_GATEWAY_OK` response, token refresh and restart with persisted login on a disposable Android 36 emulator. The client uses bearer credentials and preserves rotating cookies. Its source checkout was `fd5f5a7c521386c162e5b6173ed6c697e30f38d7`; no client changes were needed. Native sign-out with an already expired access JWT returned backend 401 while Conduit cleared its local session. Source inspection confirms sign-out is best effort and does not refresh first; this client behavior can leave the server refresh session alive until expiry. The gateway correctly forwarded the logout and did not manufacture a successful revocation. Native testing exposed the trusted forwarded hostname missing from validator subrequests after proxy hardening; this is fixed and enforced in the workerd fixture. No physical iOS client, enabled OIDC/Google/passkey enrollment, public shared-link policy, multi-region KV convergence, global quota behavior, or production hostname cutover is claimed. Generic WebSocket messages/close are verified in workerd; LibreChat conversations use SSE and do not establish an application WebSocket.

GitHub Actions passed at hardening commit `9b4649d`: [PR CI run](https://github.com/d4em0n/cf-auth-gateway/actions/runs/44678686077), [push CI run](https://github.com/d4em0n/cf-auth-gateway/actions/runs/44678680468). The suites contain 66 unit/HTTP/security tests and 7 workerd tests; formatting, lint, profiles and Wrangler build passed. Later evidence/test updates are checked again on the PR. Private evidence contains only disposable-account state and is not published as GitHub artifacts.

The optional real-LibreChat GitHub workflow has not run: its dispatcher returns 404 while this new workflow exists only on the development branch, not the default branch. Real-app checks above ran from the trusted host against Cloudflare staging. The existing public CI workflow ran successfully on the development commits; no merge was performed to enable the optional dispatcher.
