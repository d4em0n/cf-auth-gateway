Backend logout invalidates refresh sessions; a still-unexpired access JWT returned 200 after logout and expired normally. The gateway deliberately preserves that backend policy. Short QA token lifetimes differ from the owner's default 15 minutes. Parallel refresh behavior is backend timing-dependent; native clients must serialize renewal and keep rotated cookies.

Conduit **4.3.1 Android debug** passed real Cloudflare login, model/endpoint discovery, conversations, a streamed `NATIVE_GATEWAY_OK` response, token refresh, restart with persisted login and successful fresh-session logout (backend 200) on a disposable Android 36 emulator. The client uses bearer credentials and preserves rotating cookies. Its source checkout was `fd5f5a7c521386c162e5b6173ed6c697e30f38d7`; no client changes were needed. Native sign-out with an already expired access JWT returned backend 401 while Conduit cleared its local session. Source inspection confirms sign-out is best effort and does not refresh first; this client behavior can leave the server refresh session alive until expiry. The gateway correctly forwarded the logout and did not manufacture a successful revocation. Native testing exposed the trusted forwarded hostname missing from validator subrequests after proxy hardening; this is fixed and enforced in the workerd fixture. No physical iOS client, enabled OIDC/Google/passkey enrollment, public shared-link policy, multi-region KV convergence, global quota behavior, or production hostname cutover is claimed. Generic WebSocket messages/close are verified in workerd; LibreChat conversations use SSE and do not establish an application WebSocket.

GitHub Actions passed at hardening commit `9b4649d`: [PR CI run](https://github.com/d4em0n/cf-auth-gateway/actions/runs/44678686077), [push CI run](https://github.com/d4em0n/cf-auth-gateway/actions/runs/44678680468). The suites contain 66 unit/HTTP/security tests and 7 workerd tests; formatting, lint, profiles and Wrangler build passed. Later evidence/test updates are checked again on the PR. Private evidence contains only disposable-account state and is not published as GitHub artifacts.

The optional real-LibreChat GitHub workflow has not run: its dispatcher returns 404 while this new workflow exists only on the development branch, not the default branch. Real-app checks above ran from the trusted host against Cloudflare staging. The existing public CI workflow ran successfully on the development commits; no merge was performed to enable the optional dispatcher.

## YAML request-contract acceptance

The schema-v2 [YAML profile](../../profiles/librechat-v0.8.9.yaml) was deployed only to `https://gateway-stage.localup.my.id` (code deployment `50c604f8-6ab5-4740-b2c1-99a139a74998`). Original schema-v1 JSON profiles remain unchanged compatibility snapshots. The [contract guide](../request-contracts/README.md) defines all supported behavior and migration/rollback steps.

- **Source inspection:** exact login/refresh/logout and optional MFA challenge fields in the installed backend, browser data-provider and Conduit client; no route allowlist or authentication configuration changes. Required enrollment is disabled and its setup routes remain uncontracted.
- **Local tests:** 101 unit/HTTP/security tests plus 10 workerd tests cover malformed JSON, duplicate decoded keys, UTF-8, primitive fields, actual byte limits, timeout/cancellation, denied headers, unchanged validated bytes, legacy profiles and unchanged protected uploads/SSE/WebSockets.
- **Real LibreChat through local workerd and actual Cloudflare:** the full Chromium login → conversation → real model SSE → access expiry → rotating refresh → reload → logout cycle passed. Assets had zero failures; image upload/download and conversation JSON matched trusted direct responses; concurrent requests, refresh replay and an active resumable stream passed. Browser metadata confirmed login fields `email`/`password` and zero-byte refresh bodies. Local FormData is serialized before crossing Node/Miniflare fetch classes; no gateway upload code was changed.
- **Actual Cloudflare and origin logs:** 14 malformed login/refresh/logout/MFA probes were rejected before origin. Protected missing/invalid credentials, first-use validation, recognized hits and backend 401 for a recognized expired JWT retained their prior behavior.
- **Native Android through Cloudflare:** Conduit 4.3.1 passed login, model/endpoint discovery, conversation retrieval, streamed `YAML_NATIVE_GATEWAY_OK`, rotating refresh and app restart with the YAML contracts enabled. Fresh-session empty-body logout returned backend 200 and the app returned to provider selection. The previously documented expired-access logout limitation still produced backend 401 rather than a contract error.
- **Real optional MFA through Cloudflare:** a separate disposable account enrolled TOTP, signed in with a temporary challenge plus TOTP, signed in with a backup code and received a backend rejection when that backup code was reused. Unexpected challenge fields were stopped by the Worker. Required-enrollment setup, physical iOS and federated integrations remain unverified.

Private evidence: separate `contracts-*.log`/result files on the trusted staging host, metadata-only origin proof, browser request field names/counts and synthetic messages. Credentials, TOTP secrets and raw auth bodies are not CI artifacts. The optional private-infrastructure workflow remains subject to the default-branch dispatcher limitation above; public PR CI covers the deterministic suites.
